# 내 지출 관리

자산관리계획(수입을 어떤 항목에 얼마씩 쓸지)을 세워 두면, 카드 결제 문자와 은행 앱 입출금 알림을 자동으로 받아 **Claude AI가 계획 항목에 맞게 분류**하고, 항목별로 얼마 썼고 얼마 남았는지, 달력·리포트·자산 현황까지 한눈에 보여주는 가계부 앱입니다.

## 쓰는 방법 두 가지

| | 구글 시트 + AI (추천) | 이 기기에만 저장 |
|---|---|---|
| 내역 입력 | **카드 문자·은행 알림 자동 입력** + 붙여넣기 + 직접 입력 | 붙여넣기 + 직접 입력 |
| 분류 | **Claude AI** (계획 항목·설명 기준) | 키워드 |
| 저장 위치 | 내 구글 시트 (어느 기기에서나 같은 데이터) | 이 브라우저 |
| 준비 | [SETUP.md](SETUP.md) 따라 20분 설정 (붙여넣기 1번, 배포 1번) | `budget-app.html` 파일 하나만 열면 끝 |

- **구글 시트 + AI**: [SETUP.md](SETUP.md) 를 따라 구글 Apps Script 를 배포하고, 휴대폰 자동화 앱(MacroDroid)이 카드 문자와 은행 앱 알림을 보내게 설정합니다. 앱은 웹 앱 주소로 열고, 처음 한 번 접속 키를 입력합니다.
- **이 기기에만 저장**: [`budget-app.html`](budget-app.html) 을 받아 브라우저로 여세요. 디자인과 기능이 모두 이 파일 하나에 들어 있습니다. (휴대폰 파일 앱에서 누르면 "미리보기"로만 열릴 수 있으니 공유 → 크롬으로 열기를 쓰세요.)

## 화면

왼쪽 메뉴(휴대폰에서는 아래 메뉴와 **전체** 버튼)로 이동합니다.

| 메뉴 | 내용 |
|---|---|
| 홈 | 당기 수입, 남은 돈과 예산 사용률, 하루 권장 사용액, 항목별 예산 막대, 최근 내역, 자산 요약 |
| 달력 | 날짜별 지출·입금 (많이 쓴 날일수록 진하게), 날짜를 누르면 그날 내역 |
| 내역 | 날짜별로 묶은 목록, 사용처 검색, 종류·항목·결제수단 필터, 다시 분류 |
| 리포트 | 지난 기간 대비 증감, 항목별 구성 막대와 증감, 많이 쓴 곳 순위, 최근 6개 기간 수입·지출 추이 |
| 자산 | 계좌 잔액 합계(은행 알림의 잔액으로 자동 갱신), 계좌별 잔액, 카드별 이번 기간 사용액 |
| 예산 계획 | 항목별 배분 방식·금액·AI 참고 설명·키워드 |
| 설정 | 기간 시작일, 내 이름, 계좌·카드 등록, 자동 입력(서버 연결·문자/알림 주소), 백업 |

## 기능

### 자산관리계획
- **항목별 배분 방식**
  - **수입 비례(%)**: 그 기간에 들어온 돈에 비례해서 한도가 정해집니다.
  - **고정 금액**: 수입과 상관없이 매 기간 같은 한도입니다. (월세, 통신비 등)
- **비율 항목의 기준 금액**: `수입에서 고정 항목을 뺀 나머지` 또는 `전체 수입`
  - 예) 수입 300만 원, 고정 항목 합계 58만 원, 식비 30% → 나머지 기준 72.6만 원 / 전체 수입 기준 90만 원
- **설명**: AI가 분류할 때 참고합니다. (예: 식비 → "외식, 배달, 장보기")
- **키워드**: AI를 쓸 수 없을 때 사용처에 키워드가 있으면 그 항목으로 분류합니다.
- **기간별 계획**: 계획을 바꾸면 **그 기간부터** 새 계획이 적용되고 지난 기간은 그때 계획 그대로 남습니다.

### 기간과 당기 수입
- **기간 시작일**: 매월 1~31일 중 선택 (예: 25일 → 9/25 ~ 10/24). 없는 날짜는 말일로 계산합니다.
- 새 기간이 시작되면 첫 화면에서 **당기 수입(예산)** 을 입력합니다. `지난 기간과 같게` 버튼도 있습니다.

### 지출 인식과 분류
- **카드 문자 자동 입력**(구글 시트 모드): 결제 문자가 오면 AI가 날짜·금액·가맹점을 읽고 항목을 정해 시트에 기록합니다. 인증번호·광고 같은 문자는 무시하고, 같은 문자가 두 번 오면 한 번만 기록합니다.
- **은행 앱 알림 자동 입력**(구글 시트 모드): 계좌 출금·이체는 지출로, 입금은 입금으로 기록합니다. 등록한 계좌 끝 4자리로 어느 계좌인지 찾고, 알림의 잔액으로 계좌 잔액을 갱신합니다. 내 계좌끼리 옮긴 돈은 지출·수입에서 빼고, 저축 계좌로 옮긴 돈은 저축 항목 지출로 기록합니다.
  - 계좌 번호만으로 은행 거래 내역을 직접 가져오는 것은 불가능합니다(허가받은 사업자만 쓸 수 있는 마이데이터가 필요). 그래서 휴대폰에 오는 알림을 이용합니다.
- **은행 거래내역 파일 가져오기**: 카카오뱅크 등에서 받은 거래내역 엑셀(.xlsx)·CSV 를 올리면 항목 이름을 보고 날짜·금액·입출금·내용·잔액 칸을 찾아 읽습니다. 알림으로 이미 들어온 내역은 중복으로 빼고, 입금·내 계좌 이체·결제 취소를 구분하며, 마지막 잔액으로 계좌 잔액을 맞춥니다. (비밀번호가 걸린 파일은 비밀번호 없이 다시 저장해서 올려야 합니다.)
- **붙여넣기**: 카드 문자, 은행/카드 앱 내역, 엑셀 표를 붙여넣으면 한 줄씩 읽고 분류 결과를 미리 보여줍니다.
- **분류 순서**: ① 직접 분류해 둔 가맹점(기억) → ② Claude AI → ③ 키워드
- **계획이 바뀌면 다시 분류**: 홈의 `새 계획으로 다시 분류` 로 이번 기간 지출을 새 항목 기준으로 다시 분류합니다. 직접 고른 항목은 그대로 둡니다.
- **학습**: 지출 내역에서 항목을 직접 바꾸면 그 가맹점을 기억하고, AI에게도 예시로 알려줍니다.

## 구조

```
index.html, css/, js/app.js   화면 (개발용 원본)
js/logic.js                   기간·예산 계산, 알림 인식, 분류, 리포트 계산, AI 요청/응답 형식 (브라우저·서버 공용)
js/store.js                   저장 (이 기기 / 구글 시트 서버)
js/charts.js                  차트 (구성 막대, 기간별 추이)
js/xlsx.js                    엑셀(.xlsx)·CSV 파일 읽기 (외부 라이브러리 없음)
server/server.js              구글 Apps Script 서버 (시트 저장, 문자 수신, Claude API 호출)
scripts/build-standalone.js   배포 파일 생성
budget-app.html               ← 생성됨: 파일 하나짜리 앱
apps-script/Code.gs           ← 생성됨: 구글 Apps Script 에 붙여넣을 파일 하나 (로직 + 서버 + 화면)
tests/                        테스트
```

코드를 고친 뒤에는 `npm run build` 로 생성 파일을 다시 만들어 주세요. (최신이 아니면 `npm test` 가 실패합니다.)
